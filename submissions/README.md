# Submissions

Research-output submissions are tracked through GitHub issues and reviewed on
Zenodo.

Do not add individual research files or duplicated Zenodo metadata files to
this directory.

To submit a record:

1. Deposit it through your own Zenodo account.
2. Submit it to the Automation in Biology Zenodo community.
3. Open the repository's **Submit a research output** issue form.
4. Include the Zenodo record or review URL.
5. Respond to curator feedback.

Submission form:

https://github.com/rotsl/biologyautomation/issues/new?template=submission.yml

Zenodo community:

https://zenodo.org/communities/biologyautomation
